Hackathon · Oct 2026

Build the Builder

An AI agent builder for Turkish banking voice calls, built at the Freya hackathon.

  • Python
  • LLM orchestration
  • Cloudflare Workers
  • REST
See it on GitHub ↗
  • Built a Python tool that reads a bank's unstructured documents — briefs, emails, meeting notes, API contracts, PDFs — and generates a working Turkish phone agent, with no manual edits.
  • Designed a hybrid setup: the LLM handles conversation while deterministic code handles date maths, offer rules and closing logic, which made behaviour repeatable and cut response time.
  • Built a self-testing loop: the tool writes its own test calls, runs them against simulated customers, scores the results and repairs the agent.
  • Tested against 250+ edge-case scenarios, reaching 216/250 on an independent test set and 9/10 on the public benchmark.
  • Built KVKK safeguards into the generated agents — data minimisation, no exposure of card numbers — and tested them against adversarial prompt-injection scenarios.
  • Deployed a mock banking API on Cloudflare Workers covering seven services with contract-exact responses and error codes.
